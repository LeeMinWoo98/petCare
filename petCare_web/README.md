# PetCare Web

Vue 3 + Vite + JavaScript + Vue Router + Tailwind CSS 기반 프론트엔드 프로젝트입니다.

## 시작하기

```bash
cd petCare_web
npm install
npm run dev
```

## 빌드

```bash
npm run build
npm run preview
```

## 폴더 구조

```text
petCare_web/
├── index.html
├── package.json
├── vite.config.js
├── jsconfig.json
└── src/
    ├── main.js          # 앱 진입점
    ├── App.vue          # 최상위 레이아웃
    ├── assets/          # 전역 스타일 및 정적 파일
    ├── components/      # 공통 UI 컴포넌트
    ├── router/          # Vue Router 경로 설정
    └── views/           # 페이지 단위 화면
```
